# Michelle Massagens – Copacabana

Site institucional estático (HTML/CSS/JS, sem build).

## Publicar no GitHub Pages
1. Crie um repositório no GitHub e envie estes arquivos na raiz.
2. Em Settings > Pages, escolha "Deploy from a branch", branch `main`, pasta `/ (root)`.
3. O site fica em https://rodrigoaubr.github.io/michele-massagem/
